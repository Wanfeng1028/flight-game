Skylark Run — an original 3D chase-view flight game. Take off from Skylark Field, thread glowing rings over an island chain and a canyon, manage throttle, fuel, flaps and gear, and land back home. Three missions with different goals: Ring Run, Canyon Slalom and Island Hop. Keyboard and mouse controls, arcade flight physics with stall and hard-landing detection, synthesised WebAudio engine and wind sounds. No libraries, no build step, no network requests — static files only.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Fly with W/S throttle, A/D or arrow keys to steer, Space to brake, G for gear, F for flaps, R to restart, P to pause. Mouse virtual stick and wheel throttle also work.
